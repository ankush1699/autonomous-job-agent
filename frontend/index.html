Quick search

A one-off search — e.g. "Chicago jobs posted in the last 24 hours" — that does NOT touch your saved Search settings below. Any field left blank falls back to your saved setting. Results are scored and ranked by the same rubric as everything else, top matches land in Applications like any other scored job.

Search settings

Min score is the one threshold everything uses: a scored job at or above it counts as a match here, gets the green "proceed" verdict in Applications, and is what the pipeline's own gate checks. Every job that clears the score bar gets ranked (direct-to-company ATS applications and confirmed H-1B sponsorship history break ties, since those correlate with actually hearing back) — only the top N show up in Applications; the rest that cleared the bar are kept as a hidden waitlist (toolbar → "Show waitlist"), not discarded. Everything scored is marked seen so it's never re-scraped or re-billed.

ATS target companies

Greenhouse/Lever/Ashby/Workday don't support global keyword search like LinkedIn/Indeed — each board is checked per-company. Add companies you want covered directly; this is the source most likely to surface postings that never get syndicated to any job board.

LinkedIn target companies

For employers that don't run any Greenhouse/Lever/Ashby/Workday board at all — Amazon, Microsoft, Google, Meta, etc. — so they can never go in the ATS list above. Each one you add here runs one extra LinkedIn search per keyword every cycle, scoped to just that company, using your existing logged-in LinkedIn cookie. Find a company's numeric id in its public LinkedIn page source (look for urn:li:organization:<id>) — it's not the URL slug.
